F.CS308 Машин сургалт · Лекц 5 · 147 слайд

Мэдрэлийн сүлжээ, эхнээс нь тайлбарласан

Перцептроноос backpropagation хүртэл. Томъёо бүрийн доор тэмдэг бүр юу гэсэн үг болохыг бичсэн, өнгө бүр нэг утгатай. Төгсгөлд нь лекцийн тоон жишээг алхам алхмаар бүрэн бодсон.

Өнгөний түлхүүр

  • ХӨХ — ӨГӨГДӨЛ. Оролт, идэвхжилт, бодит тоо.
  • НИЛ ЯГААН — МАТЕМАТИК. Жин, параметр, томъёо.
  • ШАР — КОД / ТООЦОО. Бодит тооцоолол.
  • НОГООН — ҮР ДҮН. Forward pass, зөв хариу.
  • УЛААН — АЛДАА / BACKWARD. Градиент, анхаарах зүйл.

Хэсэг 2

Биологи → хиймэл нейрон

Хүний тархинд ойролцоогоор 80–100 тэрбум нейрон байдаг. Нейрон бүр дендрит-ээр дохио хүлээн авч, сома-д нийлүүлж, босго давбал аксон-оор дамжуулна. Холболтыг синапс гэнэ.

a = φ( Σ wi · xi )
  • xiОролтын дохио — биологид дендрит.
  • wiЖин — биологид синапсын хүч. Загвар үүнийг сурна.
  • ΣНийлбэр — биологид сома.
  • φИдэвхжүүлэх функц — биологид галлах босго.
  • aГаралт — биологид аксон.

Хэсэг 3

Перцептрон ба XOR — салбарыг унагаасан 4 цэг

z = xTw + b,    y = g(z)

Энэ бол Лаб 2-ын perceptron яг тэр хэвээрээ. Нэг давхар сүлжээ нь зөвхөн шулуун зааг зурж чадна.

Minsky & Papert 1972 онд ердөө дөрвөн цэгээр перцептроны хязгаарыг нотолсон:

Шийдэл

Дунд нь нэг нуугдмал давхарга нэмэх. Тэр давхарга өгөгдлийг эхлээд өөр орон зай руу хувиргана, тэнд шулуун хангалттай болно. Санаа нь Лаб 4-ийн kernel trick-тэй яг адил — ялгаа нь kernel-ийг гараар сонгодог бол энд сүлжээ өөрөө сурдаг.

Хэсэг 4

Идэвхжүүлэх функц — яагаад заавал шугаман бус байх ёстой вэ

Хамгийн чухал баримт

Хэрэв идэвхжүүлэгч байхгүй бол давхарга нэмэх нь утгагүй:

W₂(W₁x) = (W₂W₁)x = W′x

Матрицын үржвэр мөн л матриц. Иймээс 100 давхарга ч нийлээд нэг л матриц болно — нэг давхаргатай яг адилхан, зөвхөн 100 дахин удаан. Шугаман бус функц л давхаргад утга өгдөг.

Step

Уламжлал нь хаа сайгүй 0 → градиент дамжихгүй → сургах боломжгүй.

Sigmoid

[0,1]. 0.5-д төвлөрдөг нь муу. Лекц: «практикт хэрэглэгддэггүй».

tanh

[−1,1], 0-д төвлөрсөн тул sigmoid-оос дээр. Градиент захдаа 0 болно.

ReLU

Анхдагч сонголт. tanh-аас 6× хурдан нийлнэ. Сөрөг талдаа үхдэг.

Leaky ReLU

Сөрөг талдаа бага налуу (α≈0.02) → хаа сайгүй градиенттэй.

«Үхсэн ReLU» гэж юу вэ — тоон жишээ

# ReLU: g(z) = max(0, z),  g'(z) = 1 хэрэв z ≥ 0, эс бөгөөс 0

z = -2.0  →  g(z) = 0.0    g'(z) = 0   ← градиент 0: энэ нейрон сурахаа болино
z =  0.5  →  g(z) = 0.5    g'(z) = 1   ← градиент бүтнээрээ дамжина
z =  3.0  →  g(z) = 3.0    g'(z) = 1   ← хэчнээн том ч налуу 1 хэвээр
Vanishing gradient

Sigmoid-ын хувьд z = 5 үед налуу нь 0.0066. 10 давхаргаар дамжихад 0.0066¹⁰ ≈ 10⁻²² — градиент бүрмөсөн алга болно. ReLU эерэг талдаа налуу нь үргэлж яг 1 тул 100 давхаргаар дамжсан ч суларахгүй. 2012 оны амжилтын нэг гол шалтгаан яг энэ.

Хэсэг 5

Давхарга холбох — MLP

Хэдэн давхарга хэрэгтэй вэ

ДавхаргаЮу хийж чадах вэ
1 давхаргаЗөвхөн шугаман шийдвэрийн гадаргуу (= Лаб 2-ын perceptron)
2+ давхаргаОнолын хувьд ямар ч функцийг төлөөлж чадна (universal approximation)
Лекцийн анхааруулга

«2 давхарга хангалттай» гэдэг нь онол. Практикт асуудал нь үр дүн юм: маш өргөн 2 давхарга vs нарийн гүн загвар? Илүү олон давхарга нь ижил параметрийн тоогоор илүү сайн ажилладаг. Тиймээс «deep» learning гэдэг.

Давхарга бүр юу хийдэг вэ — төлөөлөл сурдаг

f(x) = fL( fL−1( … f₂( f₁(x) ) ) )

Лекцэд t-SNE-ээр харуулсан нотолгоо байна:

Хаана хэмжсэнАнгиудын байдал
1-р давхаргын төлөөлөлБүх өнгө холилдсон — юу ч ялгарахгүй
6-р давхаргын төлөөлөлАнги бүр өөрийн тусдаа бөөгнөрөлтэй

Энэ нь тархины харааны системтэй төстэй шатлал үүсгэдэг: V1 (ирмэг) → V2/V4 (хэлбэр) → PIT/AIT (объект) → ангилал.

Хэсэг 6

Softmax ба Cross-Entropy

Сүлжээний сүүлийн давхарга K ширхэг түүхий оноо гаргана — үүнийг logits гэнэ. Эдгээр нь магадлал биш (сөрөг ч байж болно, нийлбэр нь 1 биш). Softmax тэднийг магадлал болгоно:

ŷj = ezj ⁄ Σk ezk
  • zLogits — сүлжээний түүхий гаралт.
  • ezЭкспонент нь бүх утгыг эерэг болгоно.
  • Σ-д хуваахНийлбэрийг яг 1 болгоно → магадлал.
# 3 ангитай жишээ
logits z = [2.0,   1.0,   0.1  ]
e^z      = [7.389, 2.718, 1.105]     нийлбэр = 11.212
softmax  = [0.659, 0.242, 0.099]     ← нийлбэр нь яг 1.000

Алдагдал: cross-entropy

H(y, ŷ) = − Σk yk · log ŷk

y нь one-hot вектор (зөв ангид 1, бусдад 0). Тиймээс нийлбэрээс зөвхөн нэг гишүүн үлдэнэ — зөв ангийн логарифм.

НөхцөлТооцооАлдагдал
Зөв анги = 1-рх, загвар 0.659 гэсэн−log(0.659)0.417
Зөв анги = 2-рх, загвар 0.242 гэсэн−log(0.242)1.419
Зөв анги = 3-рх, загвар 0.099 гэсэн−log(0.099)2.313

Лекцийн зурагт: «clown fish» зургийг зөв таавал loss small, «grizzly bear» гэж андуурвал loss large. Логарифм нь итгэлтэй бөгөөд буруу таамгийг онцгой хүчтэй шийтгэдэг: магадлалыг 0.01 гэж таавал алдагдал 4.6 болно.

Лаб 3-тай холбоо

Та Лаб 3-д яг энэ алдагдлыг NumPy дээр бичсэн — хоёр ангийн тохиолдолд −y log(h) − (1−y) log(1−h). Softmax бол түүний K ангийн ерөнхий хэлбэр, sigmoid бол softmax-ын K=2 үеийн тусгай тохиолдол.

Хэсэг 7

Тензор ба batch

Зураг нэг нэгээр нь оруулбал GPU сул зогсоно. Тиймээс олныг нь нэг дор дамжуулна:

h₁ ∈ ℝNbatch × C₁
  • NbatchНэг дор боловсруулах жишээний тоо.
  • C₁Тухайн давхаргын нейроны тоо. Өөр нэрс: features, units, channels — бүгд нэг зүйл.
# Жишээ: 32 зураг, MNIST
X  : [32 × 784]      # 32 зураг, тус бүр 784 пиксел
W₁ : [784 × 128]
Z₁ = X @ W₁ + b₁  →  [32 × 128]
H₁ = relu(Z₁)     →  [32 × 128]
W₂ : [128 × 10]
Z₂ = H₁ @ W₂ + b₂ →  [32 × 10]      # 32 зураг × 10 цифрийн оноо

Хэмжээс хэрхэн таарч байгааг анзаар: дотоод хэмжээс (784, 128) үржихдээ арилж, batch хэмжээс (32) бүхэлдээ хөндөгдөхгүй дамжина. Иймээс нэг зураг боловсруулах код өөрчлөлтгүйгээр 32 зураг дээр ажиллана.

Хэсэг 8

Тогтмолжуулалт — цээжлэхээс сэргийлэх

Асуудал

Гүн сүлжээ сая сая параметртэй. Өгөгдлийн цэгийн тоо түүнээс цөөн байх нь элбэг. Тэгвэл сүлжээ зүй тогтол сурахын оронд зүгээр л бүх хариуг цээжилж мэднэ — сургалтын өгөгдөлд төгс, шинэ өгөгдөлд муу.

а) Weight decay (L2 regularization)

θ* = argmin Σ ℒ(fθ(x), y) + λ‖W‖²
  • λХэр хатуу шийтгэх вэ. Их бол жин жижиг, загвар энгийн.
  • ‖W‖²Бүх жингийн квадратын нийлбэр.

Лекцийн үг: «Бид жингээ жижиг байлгахыг илүүд үздэг.» Энэ нь Лаб 2-ын Pegasos-ын λ-тай яг ижил санаа — тэнд та λ өсөхөд ‖θ‖ буурахыг туршилтаар харсан.

б) Dropout

  • Нейронууд хоорондоо хуурамч хамаарал үүсгэхээс сэргийлнэ — нэг нейрон нөгөөдөө хэт найдаж болохгүй болно.
  • Математикийн тайлбар: энэ нь экспоненциал олон жижиг сүлжээний дундаж гэж ойлгож болно. Дундажлал нь функцийг гөлгөр болгож, загварын хэт хүчин чадлыг бууруулна.

в) Normalization давхарга

ẑk = ( zk − E[zk] ) ⁄ √Var[zk]

Дундажийг хасаж, стандарт хазайлтад хуваана. Үр дүнд нь нейрон бүр ижил масштабтай болж, сургалт тогтвортой болно. Лаб 2, 3-д та яг үүнийг оролтын өгөгдөлд хийсэн; энд сүлжээний дотоод давхарга бүрт хийж байна.

г) Double descent — орчин үеийн сонин ажиглалт

Яагаад? Параметр хэт олон үед загварыг тааруулах арга олон байдаг. Оновчлогч тэдгээрээс хамгийн энгийнийг (min-norm шийдэл) сонгодог. Лекцийн гарчиг: «Параметрүүд хэдий чинээ энгийн байна, төдий чинээ сурсан функц [сайн байна]».

Хэсэг 9

Backpropagation — лекцийн гол сэдэв

Загварт сая сая параметр байна. Тэдгээр бүрийн хувьд «энэ параметрийг бага зэрэг өөрчилбөл алдагдал хэр өөрчлөгдөх вэ?» гэдгийг мэдэх хэрэгтэй. Backprop нь үүнийг нэг дамжилтаар бүгдийг нь тооцоолдог.

Гинжний дүрэм (chain rule)

∂ℒ/∂Wl = [ ∂ℒ/∂xL · ∂xL/∂xL−1 ⋯ ∂xl+1/∂xl ] · ∂xl/∂Wl
  • [ … ]Дээрээс доош давталтаар хуримтлагдана. Үүнийг л «буцаж тархах» гэж байгаа юм.
  • ∂xl/∂WlТухайн давхаргын дотоод уламжлал — амархан, тэр давхаргын төрлөөс л хамаарна.
Яагаад хямд вэ

Параметр бүрийн хувьд тусад нь уламжлал бодвол сая сая удаа тооцоолол хийнэ. Backprop нь ∂ℒ/∂xl-ийг нэг удаа тооцоод доошоо дамжуулдаг тул нийт зардал нь forward pass-тай бараг тэнцүү. Энэ л 1986 онд салбарыг сэргээсэн санаа.

⭐ Loss layer-ийн градиент — энэ слайдыг сайн ойлгоорой

Лекцийн «Computing gradients: loss layer» слайд. Backprop-ын хамгийн эхний алхам, бүх зүйл эндээс эхэлдэг.

∂ℒ/∂WL = ∂ℒ/∂xL · ∂fL(xL−1, WL) / ∂WL
  • 1-р үржигдэхүүнЗөвхөн алдагдлын функцийн төрлөөс хамаарна (L2, cross-entropy…). Давхарга ямар ч байсан хамаагүй.
  • 2-р үржигдэхүүнЗөвхөн давхаргын бүтэц ба шугаман бусаас хамаарна. Алдагдал ямар ч байсан хамаагүй.
Яагаад энэ хуваалт чухал вэ

Энэ хоёр хэсэг бие биенээсээ хамаардаггүй. Иймээс та алдагдлын функцээ сольж болно (L2 → cross-entropy) — давхаргын код огт өөрчлөгдөхгүй. Эсрэгээр давхаргаа сольж болно (linear → convolution) — алдагдлын код өөрчлөгдөхгүй. Энэ л PyTorch-ийн модуль системийн үндэс.

Евклидийн алдагдлын градиентийг гаргах

ℒ(xL, y) = ½‖xL − y‖²   ⟹   ∂ℒ/∂xL = (xL − y)T

  1. Нийлбэр хэлбэрээр задлах

    ℒ = ½‖x_L − y‖² = ½ · Σᵢ (x_Lᵢ − yᵢ)²

  2. Нэг гишүүний уламжлал авах

    ∂ℒ/∂x_Lᵢ = ½ · 2 · (x_Lᵢ − yᵢ) = x_Lᵢ − yᵢ

# ½ нь яг л энэ 2-ыг цуцлахын тулд тавигдсан — тиймээс томъёо цэвэрхэн гардаг

  3. Бүх гишүүнийг вектор болгон бичих

    ∂ℒ/∂x_L = (x_L − y)ᵀ
Транспоз яагаад байна вэ — шалгалтанд асуудаг

Лекцийн «Matrix тооцоо» слайдын дүрэм:

Юуны уламжлалҮр дүнгийн хэлбэр
скаляр / вектор [n×1]мөр вектор [1×n]
вектор [m×1] / вектор [n×1]матриц [m×n] (Jacobian)
скаляр / матриц [n×m]матриц [m×n]

Алдагдал ℒ нь скаляр (ганц тоо), xL нь багана вектор. Эхний мөрийн дагуу үр дүн нь мөр вектор байх ёстой — тиймээс ᵀ. Хэрэв транспозгүй бичвэл дараагийн алхамд хэмжээс таарахгүй болж, ∂ℒ/∂x₂ = ∂ℒ/∂x₃ · W₁ гэсэн үржвэр ажиллахгүй.

Тоон жишээ — вектор тохиолдол

x_L = ( 0.8 )        y = ( 1.0 )
      ( 0.1 )            ( 0.0 )
      ( 0.3 )            ( 0.0 )

ℒ = ½[(0.8−1.0)² + (0.1−0)² + (0.3−0)²]
  = ½[0.04 + 0.01 + 0.09] = 0.07

∂ℒ/∂x_L = (x_L − y)ᵀ = ( −0.2   0.1   0.3 )    ← мөр вектор [1×3]

Тэмдгийг анзаар: 1-р гишүүн сөрөг (таамаг хэтэрхий бага байсан → өсгө), 2, 3-р гишүүн эерэг (таамаг хэтэрхий их байсан → бууруул). Градиент нь зүгээр нэг тоо биш — чиглэл заасан заавар.

Скаляр тохиолдол — лекцийн өөрийнх нь жишээ

x₃ = 0.313      y = 0.5

ℒ = ½(0.313 − 0.5)² = 0.017
∂ℒ/∂x₃ = 0.313 − 0.5 = −0.1869      ← сөрөг: x₃-ыг өсгөх хэрэгтэй
Нэмэлт — бас мэдэх нь зүйтэй

Softmax + cross-entropy хосыг хамтад нь уламжилбал үр дүн нь гайхалтай энгийн гардаг:

∂ℒ/∂z = ŷ − y

Яг L2-ынхтай ижил хэлбэртэй — «таамаг хасах бодит утга». Санамсаргүй давхцал биш: хоёулаа экспоненциал гэр бүлийн загвараас гаралтай. Иймээс практикт softmax ба cross-entropy-г тусад нь биш, нэг модуль болгон хэрэгжүүлдэг (PyTorch-ийн CrossEntropyLoss нь softmax-ыг дотроо агуулдаг).

Модуль бүрийн гурван томъёо

Модуль бүр дифференциалагдах бөгөөд тэдгээр нь DAG (мөчлөггүй чиглэлт граф) үүсгэж холбогдсон бол — та тэр бүх системийг backprop-оор сургаж чадна. Иймээс PyTorch бол «мэдрэлийн сүлжээний сан» биш, автомат дифференциалын систем. Мэдрэлийн сүлжээ бол түүний нэг хэрэглээ төдий.

    x₁ = W₀x₀ = ( 1·1.0 + (−3)·0.1 )  =  ( 0.7 )
            ( 0.2·1.0 + 1·0.1  )     ( 0.3 )

  4. Алдагдал

Backward pass улаан

  1. Алдагдлын давхаргаас эхэлнэ

    ∂ℒ/∂x₃ = x₃ − y = 0.313 − 0.5 = −0.1869

  2. Шугаман давхаргаар буцна — W₁-ээр үржүүлнэ

    ∂ℒ/∂x₂ = ∂ℒ/∂x₃ · W₁ = −0.1869·( 1  −1 ) = ( −0.1869   0.1869 )

  3. tanh-аар буцна — уламжлалаар гишүүнчлэн үржүүлнэ

    1 − tanh²(0.7) = 1 − 0.604² = 0.635
1 − tanh²(0.3) = 1 − 0.291² = 0.915

∂ℒ/∂x₁ = ( −0.1869·0.635 ,  0.1869·0.915 ) = ( −0.1186   0.171 )
Яагаад гишүүнчлэн үржүүлж болох вэ

tanh нь цэг бүрийн (pointwise) үйлдэл — нэг гаралт зөвхөн нэг оролтоос хамаарна. Тиймээс түүний Jacobian нь диагональ матриц болдог. Диагональ матрицаар үржүүлэх = гишүүнчлэн үржүүлэх. Лекц энэ санааг тусгайлан онцолсон.

                        ( 0.1 )

         ( −0.01186   0.0171 )

Слайд дээрх алдаа — анхаар!

145-р хуудсанд ∂ℒ/∂W₁ = x₂ · (−0.1186) гэж бичсэн байна. Энэ нь буруу — −0.1186 нь ∂ℒ/∂x₁-ийн эхний гишүүн, харин энд ∂ℒ/∂x₃ = −0.1869 хэрэгтэй.

Шалгалт: 0.604 × (−0.1869) = −0.113 ✓ (слайдын хариутай таарч байна), харин 0.604 × (−0.1186) = −0.0716 ✗. Өөрөөр хэлбэл хариу нь зөв, бичсэн тоо нь буруу. Шалгалтанд −0.1869 гэж бодоорой.

Гэрийн даалгавар (123, 124-р слайд)

  • Convolution module-ийн forward ба backward томъёог гаргаж бичих. Оролт ба гаралт нь ижил урттай 1D дохио, kernel-ийн урт K < N. Decision boundary-ийн тухай ярилцах.
  • Max pooling module-ийн forward ба backward томъёог гаргах. Оролт ба гаралт нь өөр урттай. Хил хязгаарыг хэрхэн давах тухай ярилцах.
