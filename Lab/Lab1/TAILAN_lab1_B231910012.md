## 1. Зорилго

Хичээлийн дараагийн лабораториудыг (шугаман ангилагч, логистик регресс, PCA, цаашид
PyTorch дээрх мэдрэлийн сүлжээ) ажиллуулах боломжтой Python орчныг бэлтгэж,
шаардлагатай сангуудыг суулгаж баталгаажуулах.

## 2. Ямар хувилбарыг сонгосон, яагаад

Удирдамжид дөрвөн хувилбар өгсөн:

| Хувилбар | Миний машинд тохирох эсэх |
|---|---|
| Windows + WSL (Ubuntu) | Үгүй — миний машин Windows биш |
| Windows + CUDA | Үгүй — NVIDIA GPU байхгүй |
| Windows + Docker | Үгүй |
| Ubuntu + Docker + GPU | Үгүй — NVIDIA GPU байхгүй |

Миний машин нь **Apple Silicon (arm64) дээрх macOS** тул дээрх дөрвөн зам шууд тохирохгүй.
Удирдамжийн **үндсэн шаардлага** нь "Python + шаардлагатай сангууд ажиллах орчин" учраас
macOS дээрх дүйцэх замыг сонгов:

- **Багц удирдагч:** Anaconda (`/opt/anaconda3`) — удирдамжид Windows+CUDA хувилбарт мөн
  Anaconda санал болгосон.
- **Хурдасгуур:** CUDA биш, Apple-ийн **MPS** (Metal Performance Shaders). PyTorch нь
  `torch.backends.mps` -ээр үүнийг дэмждэг тул GPU хурдасгалт боломжтой.
- **Редактор:** VS Code + Python/Jupyter өргөтгөл (удирдамжтай ижил).

## 3. Гүйцэтгэсэн алхмууд

```bash
# 1. Python орчин шалгах
python3 --version

# 2. Удирдамжид заасан сангууд
pip3 install numpy matplotlib scipy pandas scikit-learn
pip3 install opencv-python
pip3 install torch torchvision torchaudio

# 3. Баталгаажуулах
python3 check_env.py
```

> Тэмдэглэл: удирдамжийн `sudo apt-get install ffmpeg` ба `apt-get update` командууд нь
> Debian/Ubuntu-д зориулагдсан. macOS дээрх дүйцэх нь `brew install ffmpeg` юм.

## 4. Баталгаажуулалт

Орчин бүрэн эсэхийг гараар биш, **скриптээр** шалгасан: [`check_env.py`](check_env.py).
Скрипт нь удирдамжид заасан сан бүрийг импортлож, хувилбарыг нь хэвлээд, дутуугийн хувьд
суулгах командыг санал болгоно. Гаралтыг [`env_report.txt`](env_report.txt) файлд хадгалав.

Гаралтын үндсэн хэсэг:

```

Python          : 3.13.9

[ OK  ] numpy            2.3.5
[ OK  ] pandas           2.3.3

[ OK  ] opencv-python    5.0.0

Хурдасгуур төхөөрөмж

ДҮГНЭЛТ: Шаардлагатай бүх сан амжилттай суусан. Лаб 2-т бэлэн.
```

CUDA `False`, MPS `True` гарсан нь хүлээгдэж буй зүйл: Apple Silicon дээр NVIDIA CUDA
байхгүй ч PyTorch нь Metal (MPS) -ээр GPU хурдасгалт хийх боломжтой. Өөрөөр хэлбэл
удирдамжийн "windows + cuda" хувилбарын зорилго (GPU дээр сургах) биелэгдсэн.

(Бүрэн, шинэчилсэн гаралтыг `env_report.txt`-ээс харна уу — скриптийг дахин ажиллуулахад
тухайн үеийн бодит байдлыг харуулна.)

## 5. Тулгарсан асуудал ба шийдэл

| Асуудал | Шийдэл |
|---|---|
| Удирдамжийн WSL/CUDA заавар macOS дээр хэрэглэгдэхгүй | Anaconda + pip замыг сонгож, CUDA-ийн оронд MPS-ийг шалгасан |
| `torch` нь хамгийн том сан (хэдэн зуун MB) тул суулгалт удаан | Тусад нь, сүүлд суулгаж, бусад лабораторийн ажлыг зэрэг үргэлжлүүлсэн |
| Сан дутуу эсэхийг гараар шалгах нь алдаа гаргамтгай | `check_env.py` скрипт бичиж автоматжуулсан |

## 6. Дүгнэлт

- Лаб 2, 3-д шаардагдах **numpy, pandas, matplotlib, scipy, scikit-learn** бүрэн суусан
  бөгөөд эдгээрээр хийсэн лабораторийн ажлууд амжилттай ажилласан (Lab2, Lab3 хавтас).
- **opencv-python, torch, torchvision** нь дараагийн (зураг боловсруулалт, мэдрэлийн
  сүлжээний) лабораториудад хэрэгтэй тул урьдчилан суулгав.
- Орчны шалгалтыг нэг команд (`python3 check_env.py`) болгон автоматжуулсан нь дараа дахин
  шалгахад, эсвэл өөр машин дээр орчноо дахин босгоход шууд ашиглагдана.
